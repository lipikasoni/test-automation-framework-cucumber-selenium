# Selenium Cucumber Test Automation Framework

## 📌 Project Overview
This project is an end-to-end UI test automation framework built using:
- Selenium WebDriver
- Cucumber (BDD)
- Java
- Maven

It automates key user workflows such as login, product selection, and checkout.

---

## 🚀 Features
- Page Object Model (POM) design pattern
- BDD framework using Cucumber
- Reusable utilities
- Cross-browser support (optional)
- Screenshot capture on failure
- Test reports (Extent Reports)

---

## 🧪 Test Scenarios Covered
- ✅ Valid Login
- ❌ Invalid Login (Negative Testing)
- 🔒 Locked User Login
- 🛒 Add to Cart
- 🧾 Checkout Flow
- 🚪 Logout

---

## 🛠️ Tech Stack
- Java
- Selenium WebDriver
- Cucumber
- Maven

---

## ▶️ How to Run
1. Clone the repo
2. Open in IntelliJ/Eclipse
3. Run the TestRunner class
